# dex-packages

The apt package repository for Dex (`com.dex`), an Android IDE built on Termux.

The packages are built from [termux-packages](https://github.com/termux/termux-packages)
with the app package name set to `com.dex`, so they install under
`/data/data/com.dex/files/usr`. They do not work in the Termux app, and Termux
packages do not work in Dex.
